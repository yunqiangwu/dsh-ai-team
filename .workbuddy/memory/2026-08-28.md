## dsh-ai-team 插件完成首版
为 DeepSeek Harness (DSH) 实现 AI 团队协作插件 `dsh-ai-team`（双半身：Host Node + Client 浏览器）。

- 架构：每个 Agent 成员用 `git worktree` 隔离工作空间，共享同一 `.git` 仓库（完美契合"隔离工作空间+共享仓库"）。
- Host：`src/index.ts`(apply+provide('aiTeam')+tools+api)、`service.ts`(TeamService)、`git.ts`(GitBackend 可注入)、`tools.ts`(defineTool)、`config.ts`(schemastery)。
- Client：`src/client/index.tsx` 通过 `ctx.slots.register({name:'shell.overlay', id}, TeamPanel)` 注册浮动面板；`TeamPanel.tsx` 拉取宿主 `/api/ai-team` 状态。
- 已验证：host/client 双端 `tsc --noEmit` 0 错；`pnpm build` 产物路径正确（exports["./client"] → lib/client/index.js）；单元测试 6/6；集成场景真实 worktree 创建分支→提交→审查→合并成功；`scripts/verify.mjs` 通过。

### 关键 API 契约（从 node_modules 类型实测，非猜测）
- 工具：`import { defineTool } from '@deepseek-ai/dsh-tools'`；`ctx.tools.register(defineTool({name, description, parameters, output:{schema,render}, execute}))`。`parameters` 是扁平 `ParameterSchemaSpec` 映射（对象需 `additionalProperties`）；`render` 返回可变 `ContentBlock[]`（`TextBlock={type:'text',text}`）。
- Client：`import type { ClientContext } from '@deepseek-ai/dsh-client-runtime/client'`；`ctx.slots.register({name,id}, Component)`；slot 需通过 `declare module '@deepseek-ai/dsh-client-ui-slots' { interface SlotMap { 'shell.overlay': {kind:'list';scope:'root'} } }` 声明。`Context` 必须从 `@deepseek-ai/cordis` 导入（非 `cordis`）。
- 依赖按 `peerDependencies` 声明 `@deepseek-ai/*` 系列（含 dsh-client-runtime/dsh-client-ui-slots/dsh-tools/schemastery/cordis）+ react。

### 坑
- `pnpm check` 会被 pnpm 的 "ignored build scripts(esbuild)" 门禁拦截；直接用 `./node_modules/.bin/tsc -p ...` 即可。
- 默认分支可能是 master 而非 main；review 用 `base...head` 三段式对比，别用工作树 diff。
